> [!question] 1. What is Machine Learning? How is it different from traditional rule-based programming?
>
> **Answer:**
>
> Machine Learning is a branch of **Artificial Intelligence (AI)** in which a computer system learns patterns or relationships from data and uses those learned patterns to make predictions or decisions on new, unseen data. In traditional rule-based programming, the programmer explicitly defines the rules that transform an input into an output. For example, in a spam-filtering system, we could manually create rules such as **"if an email contains certain words and suspicious links, classify it as spam."** In Machine Learning, instead of explicitly writing all these rules, we provide the algorithm with many examples of spam and non-spam emails, and the algorithm learns a function that can distinguish between them. Mathematically, we can think of the task as learning an unknown function $f(x)$ that maps an input $x$ to an output $y$, where the model learns an approximation $\hat{f}(x)$. The most important goal of Machine Learning is not simply to memorize the training data but to **generalize**—that is, to perform well on previously unseen data.
