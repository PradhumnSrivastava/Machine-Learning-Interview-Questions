# Questions Inbox
11. What is the difference between generative and discriminative models? Ans- Generative models learn the underlying distribution of the data and can model how the features and target are jointly distributed. They can often be used to generate new data samples. Examples include Naive Bayes and generative language models. Discriminative models focus on learning the relationship between input features and the target, usually by directly modeling the decision boundary or conditional probability. Examples include Logistic Regression, SVM, and many classification models.

12. What is the difference between parametric and non-parametric models? Ans- Parametric models assume a fixed functional form and have a fixed number of parameters regardless of the size of the dataset. Linear Regression and Logistic Regression are examples. Non-parametric models do not assume a fixed functional form and can become more complex as the amount of training data increases. Decision Trees, KNN, and kernel-based methods are common examples. Parametric models are generally simpler and faster, while non-parametric models can be more flexible.

13. What is the curse of dimensionality? Ans- The curse of dimensionality refers to the problems that occur when the number of features becomes very large relative to the amount of available data. As dimensionality increases, data points become sparse, distance-based methods become less reliable, computation becomes more expensive, and models can become more prone to overfitting. Feature selection, dimensionality reduction, regularization, and collecting more data can help address these problems.

14. Why is feature scaling important in machine learning? Ans- Feature scaling transforms numerical features to comparable ranges so that features with large numerical values do not disproportionately influence the model. It is particularly important for distance-based and gradient-based algorithms such as KNN, K-Means, SVM, Logistic Regression, and neural networks. Common techniques include standardization, which produces a mean of approximately zero and standard deviation of one, and min-max normalization, which maps values to a specified range.

15. What is the difference between normalization and standardization? Ans- Normalization typically rescales values to a fixed range, commonly between zero and one, using the minimum and maximum values. Standardization transforms a feature by subtracting its mean and dividing by its standard deviation, producing a distribution with mean zero and standard deviation one. Normalization is useful when a bounded range is desirable, while standardization is commonly used for algorithms that perform better when features are centered and scaled.

16. What is multicollinearity, and why is it a problem? Ans- Multicollinearity occurs when two or more input features are highly correlated with each other. It can make coefficient estimates unstable and difficult to interpret, particularly in linear and logistic regression. Small changes in the data can cause large changes in estimated coefficients. Multicollinearity can be detected using correlation analysis or the Variance Inflation Factor and can be addressed through feature removal, feature combination, dimensionality reduction, or regularization.

17. What is the difference between correlation and causation? Ans- Correlation indicates that two variables have a statistical relationship, while causation means that a change in one variable directly produces a change in another. Correlation does not necessarily imply causation because the relationship may be caused by a third variable, reverse causality, or coincidence. Machine learning models can identify predictive relationships, but predictive power alone does not establish a causal relationship.

18. What is the purpose of a confusion matrix? Ans- A confusion matrix is a table used to evaluate the performance of a classification model by comparing predicted classes with actual classes. For binary classification, it contains true positives, true negatives, false positives, and false negatives. These values are used to calculate metrics such as accuracy, precision, recall, specificity, and F1-score. A confusion matrix is particularly useful for understanding the types of errors a classifier makes.

19. What is ROC-AUC, and what does it measure? Ans- ROC-AUC is a classification evaluation metric based on the Receiver Operating Characteristic curve. The ROC curve plots the true positive rate against the false positive rate at different classification thresholds. AUC represents the area under this curve and measures how well the model ranks positive examples above negative examples. An AUC of 0.5 indicates performance similar to random ranking, while an AUC closer to 1 indicates stronger discrimination between classes.

20. What is PR-AUC, and when is it preferred over ROC-AUC? Ans- PR-AUC represents the area under the Precision-Recall curve, which shows the relationship between precision and recall across different classification thresholds. It is particularly useful for highly imbalanced classification problems where the positive class is rare. For example, in fraud detection, a model may achieve a high ROC-AUC while still performing poorly at identifying the rare fraudulent cases. PR-AUC provides a more informative view of performance on the positive class in such situations.
